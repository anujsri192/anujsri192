# 🚀 What I Do

- Design and operate enterprise Kubernetes platforms (**AKS**) with Ingress NGINX, cert-manager, Cilium network policies, and HPA autoscaling
- Engineer production-grade **Terraform modules** utilizing parent-child patterns, `for_each` maps, `dynamic` blocks, and **Azure Key Vault** zero-trust integration
- Build end-to-end automated **CI/CD & DevSecOps pipelines** across **Azure DevOps**, **GitHub Actions**, and **GitLab CI** with integrated SAST, DAST, SCA, and secrets scanning
- Architect Zero-Trust **Azure Enterprise Landing Zones** (Hub-and-Spoke, Azure Firewall Premium IDPS, Bastion, Private DNS, Entra ID PIM)
- Develop enterprise infrastructure automation and SRE tooling using **Python**, **PowerShell Core**, and **Bash** on **Linux** environments
- Implement GitOps continuous delivery workflows utilizing **ArgoCD**, **Helm**, and Kustomize overlays
- Design centralized observability & SRE telemetry with **Prometheus**, **Grafana**, and **Azure Monitor / Log Analytics**
- Build **Agentic AI** workflows utilizing the **Model Context Protocol (MCP)** for autonomous cloud diagnostics, drift detection, and self-healing pipelines
- Execute strategic **Cloud FinOps** programs — rightsizing compute, pruning orphaned resources, and reserved instance arbitrage saving 35%+ in cloud spend
